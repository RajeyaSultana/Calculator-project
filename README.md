# 🧮 Calculator Application

## 📌 Overview

The Calculator Application is a front-end web project developed to perform basic arithmetic operations through a simple and interactive user interface.

This project was created to practice HTML, CSS, and JavaScript concepts such as DOM manipulation, event handling, and user input management.

---

## 🌐 Live Demo

You can view the deployed application here:

🔗 **Live Website:** https://my-claculator-app.netlify.app

---

## 🚀 Features

- Addition, subtraction, multiplication, and division operations
- Clear and reset functionality
- Interactive user interface
- Responsive design
- Real-time calculation results
- Error handling for invalid inputs

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
