# 🧮 Scientific Calculator

A modern **Scientific Calculator** built using **HTML5, CSS3, JavaScript, and Math.js**. The application provides both basic and scientific mathematical operations with a clean, responsive, and interactive user interface.

## 🌐 Live Demo

🔗 **Live Website:** https://my-claculator-app.netlify.app

---

## 📖 Project Overview

This project is a frontend scientific calculator that allows users to perform both basic arithmetic and advanced mathematical operations. It features a clean glassmorphism-inspired interface, dark/light theme switching, and keyboard support to provide an enhanced user experience.

The application uses the **Math.js** library to accurately evaluate mathematical expressions.

---

## ✨ Features

### Basic Operations
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage

### Scientific Operations
- Sine (`sin`)
- Cosine (`cos`)
- Tangent (`tan`)
- Square Root (`√`)
- Logarithm (`log`)
- Factorial (`x!`)
- Exponential (`^`)
- Pi (`π`)
- Euler's Number (`e`)

### Additional Features
- 🌙 Dark/Light Theme Toggle
- ⌨️ Keyboard Input Support
- 🗑️ Delete Last Character
- 🧹 Clear All (AC)
- ⚡ Fast Calculations using Math.js
- 📱 Responsive User Interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/RajeyaSultana/scientific-calculator.git
```

### Navigate to the Project Folder

```bash
cd scientific-calculator
```

### Run the Project

Simply open **index.html** in your preferred web browser.

No installation or additional setup is required.
